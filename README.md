
# Clothes Store

SPA web application prototype for an online shopping platform, 

## Tech Stack

Java 8, Spring Boot 1.5.2, Spring MVC, Spring Security, Spring Data JPA, 
Hibernate, MySQL, JUnit, Angular and jQuery; 
dynamic filtering using JPA Criteria API

## Architecture

SPA frontend <-> REST API <-> Application layer <-> Persistence layer <-> Database
